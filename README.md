# LangChain & LangGraph Learning Week

This folder contains my Phase 1 learning showcase for LangChain and LangGraph fundamentals during the DevSynt AI Automation Internship.

## How to Run

Open `index.html` in any modern web browser.

No build tools or dependencies are required because this is a static HTML and CSS page.

## What I Learned

This week I learned the fundamentals of LangChain, including prompt templates, chains, output parsers, memory, and tool calling. I also learned how LangGraph represents decision-making workflows using nodes, edges, conditional edges, and shared state, and how orchestrator agents coordinate specialized agents in a multi-agent system.
